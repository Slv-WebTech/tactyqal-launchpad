# Code of conduct

We want this project to be a friendly, productive place for everyone, whatever their background or experience level.

**Do**
- Be respectful, patient and constructive; assume good intent.
- Give feedback on the work, not the person; explain the *why*.
- Welcome newcomers and answer questions kindly.

**Don't**
- Harass, insult, discriminate against, or demean anyone.
- Publish others' private information.
- Spam, troll, or derail discussions.

**Enforcement.** Maintainers may edit or remove comments, issues and contributions that violate this code, and may restrict participation for repeated or serious violations. To report a concern, use GitHub's private
[security advisory form](https://github.com/Slv-WebTech/tactyqal-launchpad/security/advisories/new) or contact the maintainer through their GitHub profile.

This code is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/).
